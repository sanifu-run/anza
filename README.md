# Anza

A planned Go CLI that uses the existing Sanifu chat backend to interview participants about their own project, recommends a tailored development environment, and installs and checks the selected setup.

Status: design and implementation plan only. There is no working installer or published release yet.

Start with [the implementation plan](docs/plan.md), [product brief](docs/product-brief.md), [architecture](docs/design.md), and [parallel execution instructions](docs/execution.md). Task contracts target GPT-6-Luna and are not yet execution-certified.
