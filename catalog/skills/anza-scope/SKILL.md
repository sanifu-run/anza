# Scope a project change

Use this skill before implementation when a request leaves more than one reasonable interpretation, or when existing project work could be affected. Keep the discussion brief when the request is already precise.

## Inputs

- The participant's request and any stated priorities, audience, deadline, or constraints.
- Only the project context needed to understand the requested area, if access is authorized and available.
- Existing changes or instructions that affect the requested work.

If project files are unavailable, work from the request and label assumptions. Do not claim to have inspected a repository.

## Workflow

1. State the outcome in concrete terms: what should be different when the work is done?
2. Identify the affected user, project area, constraints, and an observable way to check success.
3. Check the smallest relevant slice of project context. Preserve uncommitted or neighboring work and follow local instructions.
4. Separate known facts from assumptions. Choose a safe, reversible default when one is clear; ask only about decisions that materially change scope or lack a safe default.
5. Name actions that need separate permission, such as publishing, spending money, accessing accounts, changing shared infrastructure, or handling sensitive data.

## Output

Provide a short scope note with:

- Desired outcome and acceptance check.
- Included area and explicit boundaries.
- Relevant constraints and unresolved assumptions.
- Any permission gate that blocks a later action.

## Check completion

The participant can tell what result to expect, how it will be checked, and which effects are outside the agreed work. Continue to planning or make the bounded change if that was requested and the scope is clear. Otherwise ask the smallest necessary question and continue independent work that does not depend on the answer.

## Continue

Keep the scope note with the task context or handoff. Update it when the participant changes the requested outcome; do not silently broaden it to include adjacent cleanup.
