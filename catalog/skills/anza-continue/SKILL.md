# Continue project work safely

Use this skill when work is resumed by the same or a different participant or agent. Start from current evidence; do not assume that an earlier plan or message still matches the project.

## Inputs

- The task outcome, scope, and prior handoff if available.
- Current project state and relevant instructions, when access is authorized.
- Recorded decisions, checks, blockers, ownership boundaries, and permission gates.

## Workflow

1. Read the task and relevant local instructions, then inspect the current state in the assigned project area. Confirm the branch or working context when available.
2. Compare current files and changes with the last handoff. Preserve work by others and identify changes whose ownership or status is unclear.
3. Separate completed work with evidence from planned, assumed, or stale work. Recheck claims that may have changed since the handoff.
4. Identify the next bounded action, its dependency and owner, and any permission or external-state gate. Continue independent authorized work when possible.
5. Record a compact handoff with outcome, current state, decisions, exact checks and results, limitations, and next action.

## Output

Provide a resume note that another person can use without rereading the full conversation: task and boundary, verified state, preserved concurrent work, decisions, checks, blockers, and next owner/action.

## Check completion

The next action follows from current evidence and does not assume stale state. Existing work is preserved, and the handoff distinguishes facts from assumptions and completed checks from planned ones.

## Continue

Update the handoff as work advances. Do not rewrite shared plans or status records unless they are assigned outputs. Publishing, spending, changing shared infrastructure, or reading private participant data still needs the appropriate authorization.
