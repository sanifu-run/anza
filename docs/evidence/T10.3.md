# T10.3 local security evidence

Status: implemented locally; certification remains `NOT RUN`. This evidence is synthetic and local. It does not claim shared Chat, provider, native Windows, or production qualification.

## Findings and fixes

- A plan could expire during executor preflight and still mutate the workspace. The executor now revalidates the canonical plan and approval immediately before each effect in fresh apply and recovery/resume paths. If expiry is detected after journaling, the operation is returned to `planned`; recovery does not infer an effect or trigger rollback.
- The process runner used `exec.CommandContext` with a cancellation callback that read `Cmd.ProcessState` concurrently with `Cmd.Wait`. A focused race run observed the data race. The runner now owns the `Start`/`Wait` lifecycle, checks the buffered wait result before cancellation, falls back to killing the direct child if tree cancellation fails, and always joins the wait result. Unix checks leader liveness through `os.Process.Signal(0)` before signaling the process group. The wait-result check and OS tree signal cannot be atomic; a narrow scheduling interval remains before the signal, so this does not prove impossibility of PID/group-ID reuse. Windows uses its existing `taskkill` tree termination without reading `Cmd.ProcessState`; Windows was not compiled or run successfully here.
- Config inverse tests show that Anza-owned values are restored only while unchanged, participant replacements are preserved, and corrupt current config is rejected. State tests show malformed state is preserved rather than overwritten.
- Session credential tests show caller/store copies are separated, formatting and JSON redact the canary, and a closed session store no longer returns credentials. This is in-memory behavior; it does not qualify native keychains or guarantee removal of all runtime memory copies.
- Model recommendations with executable command fields fail strict decoding, and command-like prose fails planner validation before a plan can be built.
