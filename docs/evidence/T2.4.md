## Behavior

`Fetch` accepts an HTTPS URL only when its exact host (or default-port hostname) is allowlisted. It applies a five-minute default request deadline, checks every redirect, enforces the caller's byte cap and catalog-provided exact size, and verifies SHA-256 before creating the digest-named cache entry. Cache hits are rechecked for regular-file type, exact size and digest, so a verified cached artifact is available without a network request. Temporary downloads are private files in a private cache directory; a failed digest, size or body check leaves no final cache file.

`Extract` supports zip and gzip-compressed tar. It validates archive paths, case-folded target collisions, Windows drive/UNC/device names, symlink and hardlink destinations, special entry types, entry counts, per-file sizes and total decompressed size before publishing. Contents are written to a private staging directory beside a nonexistent target and renamed into place only after the full extraction succeeds. The target parent must already exist and resolve to a real directory. Regular file permissions are reduced to 0644 or 0755; setuid and other special modes are not preserved.

## Reserved-name follow-up

The traversal matrix now includes zip paths ending in `COM¹`, `COM²`, `COM³`, `LPT¹`, `LPT²` and `LPT³` (also with `.txt` extensions). Before the fix, the focused `go test ./internal/download -run '^TestArchiveTraversalMatrix/zip_(COM|LPT)_superscript_' -count=1` failed for all six paths because the archive was accepted. Extending the Windows device-name set made the focused cases pass. Removing only the superscript cases from that set reproduced the six failures; the guard was restored. The post-fix full suite passed with `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go test ./internal/download -count=1` (`ok github.com/sanifu-run/anza/internal/download 2.682s`), and `GOPROXY=off GOSUMDB=off GOTOOLCHAIN=local go vet ./internal/download` passed without diagnostics.

Fixtures use `httptest.NewTLSServer` for local HTTPS download behavior and an injected in-memory transport for deterministic redirect-policy testing. The tests verify digest mismatch and oversized responses leave no final cache file, a verified cache hit makes no second network request, and malformed or oversized archives leave the extraction target absent. No real vendor URL was contacted, no artifact was installed, and no provider, account, external service or user project was accessed.

## Limits

Only zip and gzip-compressed tar are supported. Archive paths with control or combining characters and Windows-reserved device names are refused to keep path interpretation portable. Extraction and filesystem permissions were exercised on the local Darwin host only; Windows and Linux native runtime behavior was not qualified. The caller remains responsible for sourcing `Artifact` metadata, especially its expected digest and allowed hosts, from trusted catalog data. This evidence is local implementation evidence only; it does not certify installation or production behavior.
