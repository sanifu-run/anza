checks the current conversation version before calling `svc.interview`; replay

`persistTurnReservation` in `transcripts.go`. The early version check prevents
the downstream completed-request replay path from seeing an identical retry.
This also affected Anza's explicit pending-ask retry after a lost response. The
Chat candidate now checks durable request identity before rejecting a stale
conversation version.
