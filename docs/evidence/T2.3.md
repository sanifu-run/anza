## Implementation

`internal/process.Run` invokes an absolute executable with an argument array via Go's `os/exec`, uses an explicit allowlist for inherited and supplied environment keys, bounds captured stdout and stderr, and applies deadlines. `SensitiveEnv` keeps secret values separate from the serializable `Spec`; captured streams are discarded and marked redacted if an exact supplied secret occurs, so output fragments cannot reconstruct it. JSON and formatting of a `Spec` omit executable, arguments, paths, and values. Errors do not include child output or command details.

On Unix, each child starts in its own process group and cancellation sends SIGKILL to that group. On Windows, cancellation invokes the operating system's `taskkill.exe` with `/T /F`. The test suite uses local copies of the Go test binary as child fixtures. It checks that cancelling an owned tree stops its grandchild while an unrelated fixture continues. No shell, network, provider, or external project command is used by the fixtures.

## Limits

The cancellation behavior was exercised on the local Unix host; no native Windows execution was available. The Windows implementation depends on the host `SystemRoot` and `System32\\taskkill.exe`. Process-tree behavior on other Unix variants and Windows remains unqualified. Redaction detects exact configured secret values; it does not infer transformed, encoded, or partial secrets that were never emitted as an exact value. No production process, provider, external service, account, or live user data was accessed. No certification or production verification is asserted.
