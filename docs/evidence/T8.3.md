## Implemented behavior

- Diagnostics require an explicit `Request` with a local destination. `PreviewRequest` reports only the allowlisted field names, hides the destination path, and states that no network is used.
- The export contains schema version, product version, platform, a fixed readiness status, and a fixed operation. Version and platform formats and status/operation values are constrained; arbitrary config, paths, environment, conversation text, and errors are never inputs to the serialized document.
- Export creates one new file with mode 0600, does not create directories or overwrite existing files, and maps filesystem failures to static errors so a path or OS error cannot leak.
- Local deletion accepts only a safe session name and removes only `interview-<name>.json` under the supplied state directory. It rejects symlink roots and symlink/non-regular session files. Remote deletion is an injected callback receiving the existing recovery token; local removal follows successful remote deletion so failed remote requests retain local recovery state.
- Tests use synthetic fixtures, `t.TempDir`, and callbacks. No live account, service, provider, or user data is used by the test design.
