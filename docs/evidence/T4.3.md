## Behavior

The injected line wizard asks the experience level, project summary, desired first slice, optional participant-selected brief, and consent. It displays minimized machine facts and project context alongside the shared service disclosure before setup capability probing and session creation. A declined consent never starts a session. Existing interview sessions can be resumed by local session name; chat answers support skip, back/edit through the shared context update API, resume, and typed recommendation. Recovery tokens remain encapsulated by `interviewclient` and are never part of wizard output.

Partial project progress is stored through the supplied private state store. EOF returns contract exit code 3, and context cancellation returns 130 while saving a known draft. Resuming a draft re-displays the data and privacy disclosure and asks for consent again. Terminal output strips ANSI CSI controls and other control characters.
