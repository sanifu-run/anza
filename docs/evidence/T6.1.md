## Scope and behavior

- Added a pure planner that binds the catalog digest, reviewed machine/project facts, canonical recommendation, provider selections, expiry, and planned operation pre/postimage digests into the approval digest.
- Resolves pack/recipe prerequisites deterministically. Unsupported platform cells, unavailable prerequisites, mismatched installed versions, and manual strategies produce explicit manual guidance and no executable operation. Compatible installed tools are preserved.
- Codex launch-profile edits are accepted only from a planned launch-profile adapter result, only at the logical launch-profile root, and only when the current supplied config hash matches the adapter preimage. Already-present postimages produce no duplicate config write.
- Provider selections accept only `subscription` or `openrouter` for `codex` and `claude`. Recommendation command-like text and unsafe logical paths are rejected. Operations are fixed artifact/config operations; no model text becomes a command.
- Claude's adapter currently returns launch environment/arguments rather than persistent settings edits. These remain runtime-only and are deferred to T7.1; the frozen v1 Plan schema has no safe field for a launch fingerprint. No Claude persistent config mutation is omitted by this task.
