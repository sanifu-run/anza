# T9.3 Windows bootstrap evidence

Implemented a native PowerShell installer and isolated fixture matrix. The installer supports Windows amd64/arm64, downloads a versioned JSON manifest and executable only over HTTPS, checks the manifest SHA256 against a compile-time release stamp and checks the selected artifact SHA256 before creating or replacing the per-user executable. Replacement uses the platform atomic replace operation and retains a timestamped prior executable; a locked target produces retry guidance and preserves the prior file. PATH disclosure precedes the prompt, and only an explicit yes changes the user PATH. The pure PATH transformation is fixture-tested without touching this account's profile. The installer requests no elevation and never changes execution policy or machine settings.

`ReleaseBaseUri`, `Version`, and `ExpectedManifestSha256` remain explicit release stamping inputs. No production release origin or digest was available for T9.3. The default installer rejects all unstamped values before downloading or writing; T9.4 owns release digest stamping. The PowerShell source documents a process-scoped invocation (`powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\install.ps1`) for a script blocked by execution policy; it does not change stored policy. This command must be entered by the user in their own terminal.

The fixture uses in-memory scriptblock download injection and synthetic bytes only. It covers a home path with spaces and a non-ASCII character, PATH preservation, unsupported architecture, corrupt manifest, corrupt artifact, cancelled download, locked existing executable, and rejection of unstamped version/digest. It neither accesses a live release URL nor reads or writes the real user's PATH/profile.

Checks performed:

- Source inspection for HTTPS enforcement, SHA256 checks, atomic replacement, scoped user PATH write, and absence of policy-setting commands — PASS.
- `scripts/tests/bootstrap-windows.ps1` — NOT RUN: neither `pwsh` nor `powershell` is installed on the Mac host. No runtime was installed. The fixture has not been qualified on Windows; no native behavior or Windows qualification is claimed.

No admin elevation, Go build, production release, network download, or publish action was performed.
