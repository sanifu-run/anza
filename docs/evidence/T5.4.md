# T5.4 evidence: web and automation packs

## Outcome

Added 14 per-platform manual recipes for Node.js v24.21.0, two pack records, and source/license provenance. Every recipe contains one exact Node.js archive, its vendor-published SHA-256 and observed exact byte size. All recipes remain `manual`: the current facts do not expose all vendor OS/kernel/libc floors, so matching a coarse platform token cannot qualify an install as ready. Mac and Windows version facts are specifically unknown. Alpine is omitted. No Playwright install recipe or Exercise descriptor is included.

The `web` pack selects only `anza-build` and `anza-check`; it has no unconditional platform recipe prerequisites. The `automation` pack has no skills, recipes, or prerequisites; it records Playwright provenance only and does not claim usable browser automation is installed. Platform-specific Node recipes use one accepted T5.1 predicate apiece, and mutually exclusive platform recipes are not listed as pack prerequisites.

The Node.js v24.21.0 build documentation specifies Linux kernel >=4.18 and glibc >=2.28; macOS >=13.5; Windows x64 >=Windows 10/Server 2016 and Windows arm64 >=Windows 10. T2.1 facts include Linux distro identity/version but not kernel or libc; macOS/Windows runtime version can be unknown. Therefore every Node recipe requires a manual floor and OS-support check, with unknown version never qualifying. Recipes do not install globally or alter project files: the documented manual path is extraction to a user-writable managed location. No automatic update is defined. The exact v24.21.0 URL pins the release; updating requires a separate explicit catalog revision and refreshed integrity evidence. Node.js is MIT-licensed; its upstream distribution contains components under separate licenses, so notices must be retained and reviewed.

Current Playwright official installation and browser docs state Node latest 22.x/24.x/26.x, Windows 11+/Server 2019+/WSL, macOS 14+, Debian 12/13, and Ubuntu 22.04/24.04/26.04 on x86-64/arm64. Browser binaries are version-matched and may need redownloading after Playwright updates; Linux system dependencies can require OS package installation. The official v1.63.0 package metadata records Node >=20 and Apache-2.0. This evidence does not establish exact platform browser payload digests/byte sizes or clear browser artifact redistribution rights, so the automation pack has no executable Playwright recipe. Browser/automation use remains optional and manual pending exact payload, dependency, and rights evidence.
