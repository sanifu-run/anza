## Behavior covered

- Client defaults to the shared `https://vg78ulztb1.execute-api.us-west-2.amazonaws.com` API origin, accepts HTTP only for loopback synthetic fixtures, and refuses redirects so the recovery header stays on the selected origin.
- Session token is generated from 32 random bytes, represented as 64 lowercase hex characters, and persisted only through the private state store. It is sent in `X-Conversation-Token`, never URL/query data.
- Setup start/context/recommendation, capabilities, legacy ask, conversation resume, and delete use the contract routes and camelCase envelope names. Domain brief/machine-facts values are validated before transmission. Recommendations are validated against the pinned catalog version, digest, and installed IDs.
- Mutating requests persist a stable request ID before the network call. A transport failure checks shared conversation state and returns an ambiguity error rather than automatically repeating generation.
- Error handling gives explicit disabled, catalog mismatch, conflict, quota, availability, and missing/expired guidance without echoing raw response bodies.
