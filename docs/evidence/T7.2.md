## Outcome

The doctor package accepts injected read-only local probes and returns the shared `domain.CheckResult` shape. Each result records required status, an evidence kind, and a timestamp. Installed-but-unauthenticated can be represented as `action_required`. Live agent evidence is always present as `unknown` / `live` unless a separately requested check receives affirmative consent and its callback returns. With live checks denied, missing a consent callback, or encountering a consent prompt error, the live callback is never invoked. Aggregate readiness considers mandatory checks only and preserves `unsupported`, `blocked`, `failed`, `action_required`, `manual`, and `unknown` outcomes; optional live evidence does not become a hidden prerequisite.

No default executable/version/config/account probes are wired yet. Callers must supply the local probes. This package does not inspect native auth stores or initiate agent/provider traffic itself. Tests inject callbacks only; there were zero provider/agent requests, spend, login, native auth calls, or account access.
