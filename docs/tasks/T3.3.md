## Implementation steps

1. Extract the raw request/response portion of answerWithPrompt into one reusable server method in model.go. Keep answer/answerWithPrompt as compatibility wrappers that preserve citation filtering, title token limits, selected endpoint/key and provider-specific parameters.
2. Return raw text and optional usage metadata for structured setup output before citation filtering. Reuse s.client, s.key, s.model, s.endpoint and loadRuntimeCredentials; no new provider secret or independent provider router.
3. Apply bounded output/deadline/error classification to the shared helper. Do not switch the existing configured provider, enable fallback or alter the existing contact-intake prompt changes; integrate only from the reconciled peer baseline.
4. Add HTTP transport fixtures asserting both legacy payloads and setup JSON behavior, including malformed/truncated responses and absent usage. Missing usage keeps a full conservative setup reservation.
