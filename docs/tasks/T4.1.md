## Implementation steps

1. Use the shared Sanifu base URL and X-Conversation-Token protocol. Generate 32 random bytes as 64 lowercase hex characters, save only in private local state and keep it out of URLs/logs.
2. Call additive setup capability/start/context/recommendation endpoints, /api/ask for questions, and /api/conversation for resume/delete per contract revision 2. Do not parse an installation plan from free-text answers.
3. Persist stable requestId and expected versions; on network timeout read conversation state before retrying. Distinguish legacy AskResponse from typed setup recommendation and verify catalog digest.
4. Handle disabled feature, unsupported catalog, 409/429/503 and expired/missing state with useful guidance; no new session service, invitation token or model fallback.
